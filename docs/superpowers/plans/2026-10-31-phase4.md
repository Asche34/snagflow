# Phase 4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Deliver web image markup and private PDF/Excel reports with revision history.
**Architecture:** Preserve originals; persist versioned vector documents and a separate flattened JPEG through authorized RPCs. Generate reports server-side with caller credentials, paginated data, bounded photo batches, database revision allocation and private Storage.
**Tech Stack:** Existing Next 16, react-konva, react-pdf, exceljs, Zod, Supabase.
**Spec:** SNAGFLOW_BUILD_PROMPT.md sections 9, 10, 15.

## Global Constraints
- Preserve local data; do not reset Supabase or change hosted services.
- Reuse installed dependencies, Fieldwork UI and shared permission contracts.
- Database authorization is authoritative; server inputs use Zod.
- Run standalone at http://127.0.0.1:3003; stop before build; preserve private invitation configuration.

## Review Focus
- Removed/inactive actors and outsiders cannot save annotations or generate/read reports.
- Concurrent saves must not overwrite annotation drafts; concurrent reports receive unique revisions.
- Private image/report paths cannot cross project boundaries.
- Full report data must exceed the default 1,000 row cap safely; missing photos fail readably.
- All themes and 100-photo-snag PDF generation must be exercised against real local services.
