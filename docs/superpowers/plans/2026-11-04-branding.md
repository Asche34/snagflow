# SnagFlow SVG branding implementation plan

**Goal:** Export the approved S/checkmark identity and apply it to web branding and new reports.

**Design:** Faithful hand-drawn vector reconstruction of the approved raster concept. Forest green `#192D25`, orange `#C2410C`, and a white S with orange terminal on the green app tile. Keep existing Geist wordmark text in the UI. Preserve organisation report logos and add separate SnagFlow attribution.
